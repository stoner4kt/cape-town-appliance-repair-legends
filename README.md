# Cape Town Appliance Repair Legends

Professional, fully responsive static website for **Cape Town Appliance Repair Legends** — expert appliance repairs across Cape Town and the Western Cape.

## Features

- Pure HTML, CSS & JavaScript (no frameworks)
- Fully responsive (mobile-first, optimised for phones, tablets and laptops)
- SEO optimised for Western Cape / Cape Town keywords
- LocalBusiness structured data (JSON-LD)
- Privacy Policy & Terms & Conditions pages
- Contact form with client-side validation
- Modern, professional design with smooth animations
- Ready for immediate deployment to Vercel, Netlify or any static host

## Pages

- `index.html` – Home
- `services.html` – Detailed services
- `about.html` – About the company
- `contact.html` – Contact & quote form
- `privacy.html` – Privacy Policy (POPIA aligned)
- `terms.html` – Terms & Conditions

## Deploy to Vercel

1. Import this repository in the [Vercel dashboard](https://vercel.com/new)
2. Framework Preset: **Other**
3. Build Command: leave empty
4. Output Directory: leave empty (or `.`)
5. Deploy

Or use the Vercel CLI:

```bash
npx vercel
```

## Local Preview

Simply open `index.html` in a browser, or use a local server:

```bash
npx serve .
```

## Customisation

- Update phone number, email and domain in all HTML files and structured data
- Replace placeholder contact details with real business information
- Connect the contact form to Formspree, Netlify Forms or your own endpoint if desired
